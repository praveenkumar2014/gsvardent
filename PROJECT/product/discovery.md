# Product Discovery Brief

## Problem
Users can describe desired software outcomes but lack a unified workflow to decompose requirements, coordinate engineering agents, review artifacts and safely deliver work.

## Discovery questions
- Which user journeys must be useful in the first release?
- Which tasks are planning-only versus safe to execute automatically?
- What approvals should apply to code writes, secrets, network access and deployment?
- Which project types and repositories are supported at launch?
- How will users understand cost, progress, confidence and failure recovery?

## Validation plan
Conduct task-based interviews and prototype tests with founders, engineers and operators. Measure time to a reviewable plan, plan correction rate, successful completion rate, approval comprehension and unsafe-action prevention. Keep research findings separate from assumptions and record consent for research data.
