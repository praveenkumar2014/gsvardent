# User Stories

- As a User, I can create a project in a workspace where I am a member so that my work remains scoped.
- As a User, I can ask for a plan before execution so that I can review scope and cost first.
- As Staff, I can inspect task dependencies and agent outputs so that I can review work before accepting it.
- As an Admin, I can invite and revoke members with audited role changes.
- As an Admin, I can review workspace-scoped audit events without modifying them.
- As an Investor, I can view only explicitly approved read-only reports.
- As a Superuser, I can perform exceptional platform governance with strong authentication and audit evidence.
- As a workspace owner, I can inspect connector permissions and revoke access.
- As an operator, I can cancel an agent run and see its final state and artifacts.

Each story must link to acceptance criteria, role policy and automated tests.
