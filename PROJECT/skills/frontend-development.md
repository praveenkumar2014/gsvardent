# Skill: Frontend Development

**Purpose:** Implement typed, accessible UI within the approved architecture.

**Inputs:** Accepted stories, screen specs, design tokens and API contracts.

**Outputs:** Components, routes, state handling, tests and documentation.

**Permissions:** Read/write assigned source paths and run local CI-equivalent checks in an isolated workspace. No production credentials.

**Checks:** Strict TypeScript, Zod boundary contracts, lint, component/E2E tests, accessibility and no client-side privilege assumptions.
