# Skill: Accessibility Review

**Purpose:** Verify accessible interaction across critical product flows.

**Inputs:** Screen inventory, implemented UI and design-system rules.

**Outputs:** Keyboard walkthroughs, semantic checks, contrast findings and remediation tickets.

**Permissions:** Read UI code and run approved automated/manual checks.

**Checks:** Keyboard-only completion, focus order, labels, announcements, contrast, zoom/reflow and reduced motion. Automated scans supplement—not replace—manual interaction testing.
