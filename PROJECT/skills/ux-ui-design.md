# Skill: UX/UI Design

**Purpose:** Translate approved product requirements into validated user journeys, information architecture and accessible screen specifications.

**Inputs:** PRD, personas, existing design tokens and constraints.

**Outputs:** Flows, screen inventory, component behavior, responsive layouts and usability test plan.

**Permissions:** Read approved design/product documents; write design artifacts in the assigned branch. No user research outreach or external publishing.

**Checks:** Accessibility, keyboard flow, responsive behavior, clear feedback, and explicit loading/empty/error/denied states.
