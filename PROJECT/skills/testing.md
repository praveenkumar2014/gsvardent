# Skill: Testing

**Purpose:** Design and execute verifiable functional, integration and security tests.

**Inputs:** Acceptance criteria, API contracts, role matrix and risk model.

**Outputs:** Test cases, automated suites, regression evidence and defect reports.

**Permissions:** Test environments and synthetic data only unless explicit authorization states otherwise.

**Checks:** Positive and negative authorization cases, cross-tenant isolation, edge cases, deterministic fixtures, cleanup and clear pass/fail evidence.
