# Skill: Backend Development

**Purpose:** Implement authenticated, authorized domain APIs and business logic.

**Inputs:** API contracts, role matrix, database schema and acceptance criteria.

**Outputs:** Services, routes, validators, migrations as assigned, tests and audit hooks.

**Permissions:** Development/test environment only with scoped credentials; no production write authority.

**Checks:** Server-side authorization, RLS, idempotency, rate limiting, safe errors and audit coverage.
