# Skill: API Development

**Purpose:** Define and implement versioned, validated service contracts.

**Inputs:** Approved API spec, auth model and domain acceptance criteria.

**Outputs:** Request/response schemas, endpoint handlers, error catalogue, contract tests and API docs.

**Permissions:** Assigned API paths and development services only.

**Checks:** Zod validation, server-side authorization, stable errors, pagination limits, rate limits, idempotency and safe logging. Never expose internal exception detail or service credentials.
