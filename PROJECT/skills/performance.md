# Skill: Performance Engineering

**Purpose:** Measure and improve user-perceived latency and system efficiency.

**Inputs:** Defined journeys, baseline measurements, workload and performance objectives.

**Outputs:** Reproducible benchmark, bottleneck analysis and prioritized changes.

**Permissions:** Read telemetry and run bounded benchmarks in approved environments.

**Checks:** Compare like-for-like measurements; protect privacy; set rate/resource limits; test realistic concurrency; avoid unbounded load tests or production stress without approval.
