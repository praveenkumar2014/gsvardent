# Component Library Plan

## Primitives
Button, icon button, input, textarea, select, checkbox, radio, dialog, dropdown, tooltip, toast, badge, tabs, avatar and skeleton.

## Workspace components
Data table, filter bar, empty/error states, pagination, breadcrumb, workspace switcher, project card and member row.

## Product compositions
Prompt composer, plan summary, approval panel, milestone timeline, task graph, agent activity, diff viewer, terminal container, preview panel, permission manifest and audit event detail.

Each component documents props, variants, keyboard/focus behavior, loading/error state and a usage example. Reusable visual components must not embed role policy.
