# Coding Standards

Use TypeScript strict mode, explicit public types and no implicit any. Validate untrusted API, form, webhook and agent payloads with Zod. Prefer cohesive modules, descriptive naming and exhaustive state handling. Avoid silent catch blocks and swallowed failures. Never commit secrets, personal data dumps or environment files. Add tests for bug fixes and security boundaries. Review dependencies for security, maintenance and licensing. Keep diffs focused and update documentation only for verified behavior.
