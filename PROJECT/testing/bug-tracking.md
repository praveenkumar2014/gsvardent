# Bug Triage and Tracking

## Required report fields
ID, title, affected version/commit, environment, severity, priority, role/tenant scope, reproducible steps, expected result, actual result, evidence, security/privacy impact and owner.

## Severity
- Critical: active compromise, cross-tenant data exposure, privilege escalation or destructive production impact.
- High: core workflow unavailable or significant security/control failure.
- Medium: partial feature failure with workaround.
- Low: cosmetic or low-impact issue.

## Workflow
New → Triaged → In progress → Fix ready → Verified → Closed. Reopen when regression evidence exists. Security issues follow restricted disclosure and incident handling.
