# Motion and Animation Guidelines

Motion should communicate state, hierarchy and continuity—not decorate every interaction.

- Use short transitions for panel changes, menus and status updates.
- Respect reduced-motion preferences.
- Never delay essential actions for animation.
- Provide progress feedback for long-running tasks without faking percentage completion.
- Use explicit state transitions for task lifecycle changes.
- Avoid flashing, parallax that impairs reading and continuous background motion.
- Terminal and code content should remain visually stable while updates arrive.
