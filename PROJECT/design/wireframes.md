# Wireframe Briefs

## Workspace overview
Top bar: workspace switcher, search, notifications and account. Left navigation: projects, managers, skills/connectors and admin. Main area: active projects, recent runs and pending approvals.

## Project workbench
Three regions: project navigation; central prompt/plan/progress canvas; right workbench tabs for preview, files, app health and data. Bottom dock exposes terminal only when role and environment policy allow it.

## Manager view
Initiative header and status; milestone/task graph; selected task details; agent activity and approval queue.

## Admin
Member table with role and status; role-change confirmation; audit log viewer with filters and redacted detail.

These are structural briefs, not pixel-perfect final designs. Validate layout against the design system and accessibility criteria.
