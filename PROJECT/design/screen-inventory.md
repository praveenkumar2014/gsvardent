# Screen Inventory

## Public and onboarding
- Sign in / provider callback / passwordless verification
- Workspace creation and invitation acceptance
- Access denied / session expired

## Main product
- Projects overview
- Project detail and task activity
- Prompt composer with Plan and Execute modes
- Plan review and approval
- Manager initiative overview and task decomposition
- Task execution timeline and artifact review

## Workbench
- Browser preview
- File tree and diff viewer
- Application health / usage
- Terminal session with permission and resource indicators

## Governance
- Members and role administration
- Skills and connector registry
- Connector permission review and revoke
- Audit log viewer and safe export
- Account, workspace and security settings

Every screen must define loading, empty, error, denied, success and responsive states. Role and data visibility must be derived from authorized server responses.
