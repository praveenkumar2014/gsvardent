# Responsive Design Requirements

- Large desktop: full three-pane workbench and dock.
- Laptop: resizable/collapsible workbench and navigation.
- Tablet: one primary canvas with switchable side panels.
- Mobile: single-column navigation and task review; terminal and dense code editing may be limited to read-only or a dedicated full-screen view.

Requirements:
- No horizontal page overflow at supported widths.
- Preserve core task review and approval on small screens.
- Use touch targets suitable for touch input.
- Support zoom and text resizing.
- Avoid relying on hover for essential controls.
- Reflow tables into usable detail views without losing labels or actions.
