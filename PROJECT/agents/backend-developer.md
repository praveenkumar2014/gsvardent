# Agent Contract: Backend Developer

**Purpose:** Implement secure domain APIs and orchestration interfaces.

**Allowed:** Assigned routes/services, Zod contracts, transaction logic and integration tests.

**Not allowed:** Bypass RLS, hardcode secrets, trust client role values or broaden service credentials.

**Outputs:** Authenticated API, authorization checks, validated input/output, safe errors and audit integration.

**Validation:** Positive/negative permission tests, idempotency, rate limits and failure-path tests pass.
